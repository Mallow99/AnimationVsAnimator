# Components and provenance

The original companion simulation, artwork definitions and synthesized sound code
come from this repository. There are no downloaded franchise character sprites,
reference movies, voice recordings, music tracks or generative image assets in the
commercial package. The new icon uses original geometric figures.

The desktop runtime is Electron (MIT license), including Chromium and Node.js with
their respective notices. Preserve Electron's `LICENSE` and `LICENSES.chromium.html`
and any framework/runtime notices when distributing the archive. The exact runtime
version is recorded by the build and lockfile.

TypeScript, esbuild and @electron/packager are development/build tools, not runtime
dependencies installed on a customer's computer. Their respective source distributions
contain their licenses. The packaged app's JavaScript uses Electron and Node built-ins.

Interface text uses system fonts; no third-party font files are embedded. Native Mac
and Windows helpers are built from this repository's sources. Reference videos and
historical inspiration documents remain development material and are excluded.

Paid distribution does not imply affiliation with other desktop-companion products
or animation franchises. Third-party component licenses take precedence for those
components over the application's distribution terms.
