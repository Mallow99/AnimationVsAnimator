# Privacy

Mallow Desk Buddies' commercial edition has no account, advertising, analytics,
cloud AI requests, model downloads, subscription or browser extension connection.
The app does not run the development project's browser pairing server.

Names, preferences, moods, friendships, belongings, artwork, conversations and memories
are stored locally in the app's data folder. Chat history is bounded to 240 entries /
120,000 text characters per buddy. Oldest transcript entries expire; saved memories
are separate. Export before clearing a conversation if you want to retain it.

On Mac, a native helper remembers the front application locally so clicks on a buddy
can return focus. With desktop features off it does not enumerate windows.
Window climbing uses native window positions. Optional active-app awareness uses the
front app name/window title and accessible element geometry locally. Optional window
movement and cursor mischief act only when enabled. They start off. No screen image,
keystroke log or window content is uploaded by this edition.

Chat exports and full backups are files you choose to save. They can contain personal
details you shared. Keep them somewhere private. Full backups exclude provider keys,
OS credential stores and development browser-pairing tokens.

The storefront and payment provider handle purchases under their own privacy policies.
Opening an external help link uses your regular browser. OS security checks are managed
by your operating system, independently of this app.

New conversation clears only the selected buddy's chat/story state. Memories, items
and friendships remain. Removing the entire local data folder after quitting deletes
the saved app state; this cannot be undone without a backup.
