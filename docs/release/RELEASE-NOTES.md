Mallow Desk Buddies is a little group of stick-figure companions that live on your desktop. This is a free **test build** for Windows 11 (x64) and Apple Silicon Macs.

**To run it:** download the ZIP for your computer, extract all of it, then open `Mallow-Desk-Buddies.exe` (Windows) or drag `Mallow-Desk-Buddies.app` to Applications and open it (Mac). `START-HERE.txt` inside the ZIP has the same steps. No installer, account, internet connection or extra downloads are needed.

**Expect a security prompt.** The apps are not code-signed. Windows shows "Windows protected your PC": choose More info, then Run anyway. On a Mac, follow `INSTALL.md` in the ZIP. Only run a ZIP you got from this page.

**What is inside:** up to five customizable buddies with their own moods, belongings, friendships and memories; petting, picking up and tossing; reading, drawing, catch, TV, handheld games, Pong, Othello and cartoon sparring; furniture; built-in conversation; automatic saves with backup export. Window climbing, sounds and cursor mischief are optional and start off. A bonus code unlocks a sixth buddy.

**Optional Local AI:** if you already run Ollama on the same computer, Settings → Local AI lets buddies answer with one of your own models. It is off by default, sends nothing over the internet and never downloads a model.

Each ZIP was built on its own operating system and automatically unzipped, started, saved, quit and restarted before being published here. It has not been hand-tested on every setup: if something breaks, please say which computer and system you used and what happened. `FEATURES.md`, `PRIVACY.md` and `RECOVERY.md` are inside the ZIP, and `release-source.json` records the exact source it was built from.
