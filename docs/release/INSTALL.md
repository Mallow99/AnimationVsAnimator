# Mallow Desk Buddies

Little offline companions for your desktop. This archive is a release candidate.
Check its `release-source.json` and the project's release notes for the exact version
and tested operating systems. Native acceptance is still pending for rc.1.

## Windows

1. Extract the whole ZIP to a normal folder.
2. Open `Mallow-Desk-Buddies.exe`. Keep its accompanying files together.
3. Settings and Quit are in the tray icon near the clock; it may be in the overflow menu.

Target: Windows 11, x64. You do not need Node, a developer environment or an AI key.
The executable is not certificate-signed and Windows may show a reputation warning.
Only run the archive you obtained from the project's official release/store page.
Do not disable Windows security features to install it.

## Apple Silicon Mac

1. Extract the ZIP and move `Mallow-Desk-Buddies.app` to Applications.
2. Open the app. Its controls and Quit are in the menu-bar icon.
3. Window climbing is optional. Enable it in Settings if you want it; the floor
   works without it. If macOS requests Accessibility, grant it to this app.

Target: Apple Silicon, macOS 13 or newer. Intel Macs are outside this edition.
The native helper is included. Xcode, command-line developer tools and Node are not needed.
This candidate uses ad-hoc signing, not Apple Developer ID signing or notarization.
macOS may block it as an unidentified developer. Review Apple's app-specific instructions:
https://support.apple.com/102445. Do not disable Gatekeeper or run blanket security-removal commands.

## Make yourself at home

- Rub gently to pet a buddy. Click for a poke; drag to pick up, release to drop or throw.
- Double-click to talk. Built-in dialogue knows familiar topics and branching stories;
  it is not a general-purpose AI assistant.
- Right-click for the bag and activities. Supplies include objects and furniture.
- Picking up a tool carries it; choose Use for active controls. Escape exits interactions.
- Choose one to five buddies in Settings. Putting someone away preserves their things.
- Pause, Hide/Show and Quit are always available in the menu-bar / tray menu.
- Sound and desktop mischief start off. Settings explains the optional controls.

## Updates and removal

Quit before replacing the app or Windows app folder with a newer version. Downloads are
manual. The save directory remains `animation-vs-animator` to retain earlier project saves.
Uninstall by quitting and removing the app folder. Saves remain until you deliberately
remove their folder; Settings → Open save folder locates it. Back up first.

Primary-monitor play is supported. Cross-monitor roaming is outside this edition.
See RECOVERY.md for save problems and PRIVACY.md for local data details.
